Propiedades CSS

border-top

border-top es un propiedad de css que sirve para establecer el borde superior de un elemento

border-bottom

border-bottom es un propiedad de css que sirve para establecer el borde inferior de un elemento

margin

margin es un propiedad de css que sirve para establecer el margen de un elemento

padding

padding es un propiedad de css que sirve para establecer el relleno de un elemento

vertical align

vertical-align es un propiedad de css que sirve para establecer la alineación vertical de un elemento

text-indent

text-indent es un propiedad de css que sirve para establecer la indentación de un elemento

text-wrap

text-wrap es un propiedad de css que sirve para establecer el ajuste de texto de un elemento

text-stroke

text-stroke es un propiedad de css que sirve para establecer el trazo de texto de un elemento
