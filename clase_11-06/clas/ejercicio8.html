Lenguajes de Programación - Definiciones

Python
Lenguaje de programación interpretado de alto nivel, conocido por su simplicidad y legibilidad. Ideal para principiantes y muy usado en ciencia de datos e IA.
JavaScript
Lenguaje de programación interpretado, orientado a objetos, utilizado principalmente para crear páginas web interactivas.
Java
Lenguaje de programación orientado a objetos, diseñado para ser multiplataforma bajo el principio "escribir una vez, ejecutar en cualquier lugar".
C++
Lenguaje de programación multiparadigma que extiende el lenguaje C. Muy utilizado en sistemas embebidos, videojuegos y aplicaciones de alto rendimiento.
